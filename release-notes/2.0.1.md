# SharkOptimizer 2.0.1

- Opt-in automatic Game Boost for saved game profiles while SharkOptimizer runs, including in the tray.
- Detect games launched outside SharkOptimizer using their detected executable paths.
- Review automatic profile actions before enabling; automatic app-closing requires a separate choice.
- Restore temporary session settings after game exit, with a fifteen-second grace period for process handoffs.
- Session recap notifications link to Recent sessions, including duration and restoration status.
- Automatic profiles remain off by default and require enabling again after backup import.

Enable this under Game Boost: select a detected game, choose its actions, enable Automatic Game Boost, and save/review the profile. Keep SharkOptimizer running. If Windows prevents reading a game's executable path, detection remains unavailable.
