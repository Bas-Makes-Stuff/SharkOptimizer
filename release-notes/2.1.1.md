# SharkOptimizer 2.1.1

- Native C# / WPF app with a compact dashboard, consistent Fluent icons, live system gauges, and a smoother loading-screen transition.
- Windows optimization review, reusable presets, game profiles, game-session tools, cleanup, network diagnostics, and restore history.
- Windows language detection on first launch, saved language selection, interface scaling, accent colors, and reduced-motion controls.
- Background scanning of existing tweaks, with separate status for changes made outside SharkOptimizer. These detections do not create undo records.
- Restored app-preference reset, saved game-scan clearing, automatic restore-point preference, and legacy cleanup schedule preference import.
- Closing the app sends it to the tray. The installer creates Desktop and Start Menu shortcuts and enables sign-in to the tray.
- Automatic update checking and background downloads from the official GitHub release channel. Downloaded updates wait for confirmation before installation.

Use `SharkOptimizer-Setup.exe` to install or update the app.
